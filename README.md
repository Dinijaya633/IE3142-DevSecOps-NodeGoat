\## Application Overview



NodeGoat is an intentionally vulnerable open-source web application developed

by OWASP to demonstrate the OWASP Top 10 in a Node.js context.



\- \*\*Backend:\*\* Node.js 20 / Express 4

\- \*\*Database:\*\* MongoDB 4.4

\- \*\*Templating:\*\* Swig

\- \*\*Containerisation:\*\* Docker + Docker Compose
